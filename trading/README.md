# «Торговый офис» — автономная компания из ИИ-агентов на бирже (Финам)

> Черновик v1, 28.09.2026. Это не финансовая рекомендация и не обещание дохода.
> Рынок акций может принести убыток, в том числе крупный.

## Смысл

Деньги работают на бирже по **заранее проверенным правилам**, без эмоций и без
ежедневного участия владельца. Агенты делают рутину: анализируют рынок, считают
риск, выставляют заявки и пишут отчёт. Человек задаёт лимиты и может нажать
стоп-кран.

## Честно про цели

Настоящий конкурент этой компании — **не индекс, а фонд денежного рынка**
(LQDT, SBMM и т. п.), который приносит почти ключевую ставку без риска.
Поэтому цель такая:

1. **Главная:** обогнать фонд денежного рынка на длинной дистанции (3+ года).
2. **Ограничение:** просадка не больше 15 % от пика, иначе агенты сами
   останавливаются и ждут решения владельца.
3. **Автономность:** владелец тратит ≤ 15 минут в месяц — прочитать отчёт.

## Проверка стратегии на реальной истории Мосбиржи

`python3 backtest.py 2014` — 20 голубых фишек, дневные данные ISS, комиссия и
проскальзывание 0,1 % на сделку, свободные деньги лежат под ставку денежного
рынка. Дивиденды не учтены ни в стратегии, ни в индексе.

| 2014-10 — 2026-09       | Доходность в год | Макс. просадка | Итог  |
| ----------------------- | ---------------- | -------------- | ----- |
| Стратегия               | +19,2 %          | −29,0 %        | ×8,07 |
| Индекс IMOEX (без див.) | +4,2 %           | −55,3 %        | ×1,64 |
| Фонд денежного рынка    | +10,2 %          | 0 %            | ×3,16 |

| 2018-10 — 2026-09       | Доходность в год | Макс. просадка | Итог  |
| ----------------------- | ---------------- | -------------- | ----- |
| Стратегия               | +9,0 %           | −29,0 %        | ×1,99 |
| Индекс IMOEX (без див.) | −0,9 %           | −55,3 %        | ×0,93 |
| Фонд денежного рынка    | +10,6 %          | 0 %            | ×2,22 |

**Что важно увидеть в этих цифрах:**

- Почти весь выигрыш дали три года: 2016 (+112 %), 2018 и 2023. Без них
  стратегия давала ~6 % в год — **хуже** денежного рынка (~10,5 %).
- **С 2018 года стратегия проиграла фонду денежного рынка** (+9,0 % против
  +10,6 %), да ещё с просадкой −29 %. Дивиденды, которые получает стратегия,
  пока держит акции, добавили бы ей ~2–3 % в год — это примерно ничья.
- **В 2024–2026 стратегия проиграла фонду денежного рынка**: при ставке
  16–21 % безрисковый доход был выше, чем от акций.
- Бэктест завышен: в списке — сегодняшние лидеры (ошибка выжившего), а
  реальное исполнение всегда хуже расчётного.

**Вывод:** доказанного преимущества над безрисковым фондом у этой стратегии
нет. Поэтому устройство компании такое:

- **Ядро (большая часть денег)** — фонд денежного рынка. Это уже «автономный
  доход» почти без риска.
- **Спутник (небольшая часть)** — стратегия агентов. Сначала на бумаге,
  потом на небольшой сумме. Каждый месяц результат сравнивается с ядром; если
  через 6–12 месяцев спутник отстаёт, его выключают или меняют стратегию.
- Новые стратегии добавляются только после бэктеста, который обгоняет
  денежный рынок **на периоде с 2018 года**, а не только на удачных годах.

## Стратегия (strategy.py)

Раз в месяц:

1. Если индекс IMOEX ниже своей 200-дневной средней — всё в деньги.
2. Иначе берём акции с положительной доходностью за 6 месяцев, которые выше
   своей 200-дневной средней, и покупаем 4 лучшие, по 25 % каждая.
3. Свободные деньги — в фонд денежного рынка (в живом режиме докупается
   вручную или в следующей версии агентом).

## Агенты

| Агент           | Файл                | Что делает                                                               | Право вето |
| --------------- | ------------------- | ------------------------------------------------------------------------ | ---------- |
| Аналитик        | `agents/analyst.py` | Данные Мосбиржи → целевой портфель и объяснение каждого выбора           | нет        |
| Риск-менеджер   | `agents/risk.py`    | Лимит просадки 15 %, ≤ 25 % в одну бумагу, без плеча и шортов, стоп-кран | **да**     |
| Трейдер         | `agents/trader.py`  | Разница «есть / надо» → лимитные заявки в Финам (или бумажные сделки)    | нет        |
| Журнал (память) | `memory/journal.md` | Каждый день: капитал, просадка, решения и почему                         | —          |

Оркестратор — `run.py`: аналитик → риск → трейдер → журнал. Запуск раз в день,
сделки — только раз в месяц (или сразу, если риск-менеджер требует выйти в
деньги).

## Как запустить

**Этап 1 — бумага, 1–2 месяца (без денег и без токена):**

```bash
cd trading
python3 backtest.py 2014   # проверка на истории
python3 run.py             # один рабочий день офиса в бумажном режиме
```

**Этап 2 — реальные деньги, небольшая сумма:**

1. Откройте в Финаме **отдельный счёт** под робота (не основной).
2. В личном кабинете Финама: «Торговое API» → создать токен. **Не
   присылайте токен в чат и не коммитьте его.** Укажите его только в
   переменных окружения на машине, где работает робот.
3. Запуск:
   ```bash
   export FINAM_SECRET=...        # токен
   export FINAM_ACCOUNT_ID=...    # номер отдельного счёта
   export TRADING_CAPITAL=50000   # сколько рублей максимум доверено агентам
   TRADING_MODE=live python3 run.py
   ```
4. Первый живой запуск — вместе с человеком: проверить, что заявки и размер
   лота совпадают с ожидаемыми.

**Этап 3 — автономность:** расписание раз в будний день в 10:40 МСК (cron на
сервере или VPS). Ежемесячно владелец читает журнал и сравнивает результат с
фондом денежного рынка.

**Стоп-кран:** создать файл `memory/STOP` — агенты перестают торговать. Он же
создаётся автоматически при просадке больше 15 %.

## Задачи на 90 дней

- [ ] Месяц 1: бумажная торговля, ежедневный журнал, сверка с бэктестом.
- [ ] Месяц 2: живой счёт на небольшую сумму; проверка лотов, комиссий,
      исполнения заявок.
- [ ] Месяц 3: агент «денежный рынок» — свободный кэш автоматически в
      LQDT; отчёт аналитика раз в месяц; решение, увеличивать ли капитал.
