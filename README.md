# SpecAI
Маркетплейс аренды спецтехники (краны, экскаваторы, самосвалы и т.д.) для строительной отрасли. Целевые города запуска: Набережные Челны, Нижнекамск, Елабуга, Заинск.

## Статус

Flutter-приложение в **демо-режиме**: полный сценарий работает без внешних сервисов —
телефон → код подтверждения → профиль → каталог/карта → заказ → отклик исполнителя →
принятие → трекинг на карте → чат → завершение заказа. Исполнители на карте показывают
цену и статус (свободен/занят) — по аналогии с такси-сервисами.

Реальный Firebase (SMS-авторизация, Firestore) ещё не подключён — сейчас всё работает
на встроенном моковом бэкенде (`lib/data/demo_data_store.dart`).

## Запуск

```bash
flutter pub get
flutter run -d chrome
```

Демо-код подтверждения показывается прямо на экране (жёлтая плашка) — реальная SMS не отправляется.

## Подключение реального Firebase (когда будет готово)

```bash
dart pub global activate flutterfire_cli
flutterfire configure
```
Затем раскомментировать инициализацию Firebase в `lib/main.dart` и заменить вызовы
`DemoDataStore` на реальные Firebase Auth/Firestore сервисы.

## Монетизация (заложено, не активировано)

- Комиссия с исполнителей: `DemoDataStore.commissionRatePercent` (сейчас только отображается,
  реальное списание не реализовано).
- Приём донатов от заказчиков — заглушка на экране профиля.
- Приём платежей (карты/СБП) **не подключён**: платёжный шлюз нужно интегрировать отдельно,
  когда будет выбран провайдер (ЮKassa/Тинькофф и т.п.).
