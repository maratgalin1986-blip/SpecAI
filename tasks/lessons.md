# Уроки (обновлять после каждой поправки владельца или своей ошибки)

Читать в начале каждой сессии. Формат: что случилось → правило.

1. Владелец смержил PR за минуту до последнего пуша, и правка «звук по умолчанию» не попала на сайт.
   → Не дописывать коммиты в PR, который владелец может мержить; если дописал — проверить, что
   коммит в `main` (`git merge-base --is-ancestor`), и при необходимости открыть новый PR.
2. Агент в изолированной копии стартует от `main`, а не от рабочей ветки.
   → В задании агенту первой строкой: `git fetch origin <ветка> && git reset --hard origin/<ветка>`.
3. Агент выполнил `pkill -f "next build"` и мог убить чужую сборку; мой `pkill` убил собственный shell.
   → Останавливать процессы только по PID, проверенному по `/proc/<pid>/cwd`; никаких `pkill -f`.
4. Два `async redirects()` в `next.config.mjs` — второй молча перекрыл первый.
   → После правки конфигурации проверять результат (`.next/routes-manifest.json`, `curl -I`).
5. Тесты на время выполнения падали под нагрузкой других агентов.
   → Мерить CPU-время (`process.cpuUsage`), а не время по часам; 3D-тесты могут сами пропускаться — перепроверять при низкой нагрузке.
6. Кнопка звука срабатывала дважды: жест будил звук, клик тут же выключал.
   → Обработчики «первого касания» не должны срабатывать на элементах-переключателях.
7. Скриншоты агентов делались с заглушками видео — оценка «как в кино» без настоящих роликов неверна.
   → Для визуальной проверки перекодировать настоящие mp4 в WebM и подставлять их.
8. Владелец пишет голосом: «зарплату убрать» = «оплату убрать», «лирным» = «жирным».
   → Понимать смысл по контексту; если смысл меняет решение — уточнить одной фразой.
9. По IP посетителей не узнаём (152-ФЗ, ненадёжно) — только память в браузере с согласием.
10. Перед «готово» — доказать работу: тесты, сборка, e2e, скриншоты на телефоне; отчёт с цифрами.
11. Mixkit отдаёт curl'у 429 (проверка Cloudflare), а Chromium из Playwright падал на ERR_CERT_AUTHORITY_INVALID.
    → Добавить CA прокси в NSS (`certutil -A -d sql:$HOME/.pki/nssdb -n ccr-agent-proxy -t "C,," -i /root/.ccr/agent-proxy-ca.crt`),
    списки и id брать из страниц тегов `mixkit.co/free-sound-effects/<тег>/` через Playwright, а сами файлы — curl'ом
    с `assets.mixkit.co/active_storage/sfx/<id>/<id>.wav` (там проверки нет). Поиска по `?query=` у Mixkit нет.
12. e2e локально: `cd apps/web && NODE_PATH=/opt/node22/lib/node_modules npx playwright test -c e2e/playwright.config.ts` (иначе конфиг не находит модуль `playwright`). Перед `pnpm lint` удалять готовые worktree агентов — eslint лезет в их `.claude/worktrees/*/public/sw.js`.
13. Ночная запись голосов: фоновая задача агента живёт не больше 2 ч, контейнер может перезапуститься, а
    `until ! pgrep -f X` находит сам себя и ждёт вечно.
    → Долгие задания — через `setsid nohup … &` с чекпойнтом (`stroyka-voices-hybrid.py --state`), коммитить
    готовые mp3 каждые полчаса; ждать процесс по PID (`ps -p`), не по `pgrep -f`.
14. Агент по UX выключил звук по умолчанию, хотя владелец 2026-10-03 решил «включён по умолчанию».
    → Перед правкой поведения, о котором есть решение владельца (docs/owner-requests.md,
    tasks/lessons.md), сверяться с ним; замечание проверки не отменяет решение владельца.
15. Первый обзор кода по `REVIEW.md` на уже слитом PR #58 нашёл 9 настоящих ошибок (обновлённое
    предложение по гостевой заявке не доходило до Telegram владельца; успешный вход сбрасывал счётчик
    попыток по IP; «Мира» без запятой считалось городом; «пишите в Телеграм» становилось городом
    заявки; геокодер мог работать 48 с при лимите функции 10 с; водитель без машины оставался на
    карте; приложение снимало с линии при каждом запуске).
    → `/code-review` по диффу перед каждым пушем, до слития, а не после. Найденное исправлять с
    тестом, который падал до правки.
16. Обновления 16–17 октября ушли в Expo только для Android (`--platform android`), а Expo Go
    просит runtime «exposdk:57.0.0», не «0.1.0» APK: на iPhone владельца — «AppLoaderTask …
    could not launch an update».
    → Публиковать `--platform all` и дважды: обычной командой (APK) и с `EXPO_GO_UPDATE=1`
    (Expo Go); проверять ответ `u.expo.dev` для `expo-platform: ios` и обоих runtime.
17. Агент по донатам привёл в комментарии кода первые 8 цифр настоящей карты владельца как
    пример формата; репозиторий публичный. Поймано до пуша, коммит переписан.
    → Перед слиянием работы агента: `git diff <база> <ветка> | grep` по реквизитам владельца
    (карта, телефон, паспорт); в примерах — только тестовые номера (4111 1111 1111 1111).
    Реквизиты живут в базе (`AppSetting`) и вводятся владельцем в меню администратора.
18. Разбор ответов опроса в группе: `\bагп\b`, `\bкму\b`, `тр\b` никогда не срабатывали — в JavaScript
    `\b` знает только латиницу и цифры; поймал `/code-review`, тесты были только на латинских моделях.
    → Для русских слов — явные границы `(?<![a-zа-яё0-9])…(?![a-zа-яё0-9])` (или только начало слова,
    чтобы ловить падежи: «ивановца», «шакмана»); в тестах — русские примеры в разных падежах.
