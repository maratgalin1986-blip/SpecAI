# Требования

## Офис и расписание

- R1. Офис работает без владельца: по расписанию (раз в час, рабочее окно по Москве) выполняется
  один шаг плана обхода — пара «агент × ниша × город» — и создаются новые кандидаты.
- R2. План обхода — список строк «агент; ниша; город», идёт по кругу; владелец может изменить
  его в админке; по умолчанию агент «Подрядчики» обходит крупные города России, агент «Сайты» —
  несколько ниш в городах, начиная с Набережных Челнов и Казани.
- R3. Раз в день утром (по Москве) владельцу в Telegram приходит сводка: сколько кандидатов
  нашёл каждый агент, список «кому звонить сегодня» (имя компании, город, ниша, телефон, ссылка
  на превью) и ссылка на раздел «Офис» в админке. Без кандидатов — короткая строка «за ночь
  ничего нового».
- R4. Каждый прогон записывается в журнал (агент, ниша, город, найдено, создано, ошибка) и виден
  в админке.

## Поиск кандидатов

- R5. Источник кандидатов — открытые данные OpenStreetMap (Overpass API) без ключа: компании
  выбранной ниши в радиусе города, у которых есть название и телефон и **нет** сайта.
- R6. Один и тот же объект (по идентификатору источника или по телефону) не становится
  кандидатом дважды; кандидат с уже существующей на платформе компанией (тот же телефон) не
  создаётся для агента «Подрядчики».
- R7. Владелец может добавить кандидатов вручную: строки «Название; телефон; адрес или город»
  в админке; они проходят тот же путь (страница, скрипт, список звонков).
- R8. Источники с ключом (2ГИС, Яндекс Геопоиск) — вне объёма; место для них предусмотрено
  (интерфейс источника), ключ — PLACEHOLDER — уточнить у владельца.

## Страницы

- R9. Агент «Сайты» строит страницу-визитку по данным карточки: название, ниша, услуги ниши
  (словарь), адрес, часы, телефон, кнопки «Позвонить» и «Написать в WhatsApp», ссылка на карту;
  без выдуманных отзывов, фото, цен и цифр.
- R10. Агент «Подрядчики» строит страницу исполнителя: название, город, виды техники (из названия
  и тегов карточки, иначе «спецтехника»), кнопка «Заказать технику» на форму заявки платформы с
  городом, блок «Это ваша компания? Встать на линию бесплатно» со ссылкой на регистрацию
  исполнителя с предзаполненными данными.
- R11. До согласия страница доступна только по секретной ссылке превью (`/preview/<токен>`),
  с пометкой «Предпросмотр» и `noindex`; в поиск и карту сайта не попадает.
- R12. После отметки «Согласился» страница публикуется: вариант 1 — `/s/<slug>`, вариант 2 —
  `/p/<slug>`; до публикации и после отказа эти адреса отвечают 404.
- R13. Телефон кандидата показывается на публичной странице только после публикации (согласия);
  превью показывает телефон (его видит только владелец по секретной ссылке).

## Звонок и результат

- R14. Для каждого кандидата готов текст звонка по шаблону агента (приветствие, что сделали,
  ссылка на превью, предложение, ответ на «сколько стоит»/«зачем»), по-русски.
- R15. Владелец отмечает результат: «Согласился» (публикует), «Перезвонить» (дата), «Отказ»,
  заметка — в админке `/admin/office`; «Перезвонить» попадает в утреннюю сводку в свой день.
- R16. Цена сайта и поддержки (вариант 1) — в одном месте (`lib/prices.ts`, редактируется через
  настройку в админке), в текстах звонка и на странице цена берётся оттуда; значения по умолчанию —
  PLACEHOLDER — уточнить у владельца.
- R17. Исполнитель, пришедший по ссылке со страницы `/p/<slug>`, при регистрации помечает
  кандидата как «зарегистрировался» (видно в админке и в сводке).

## Границы и безопасность

- R18. Кандидатам ничего не отправляется автоматически (ни SMS, ни e-mail, ни мессенджеры);
  любой контакт — звонок владельца.
- R19. Все маршруты админки и запуска — только для админа площадки; крон — по `CRON_SECRET`;
  публичные страницы не отдают id, заметки, токены и статусы.
- R20. Схема — только новые модели и колонки с default; без enum.

## Вне объёма

- Собственный домен клиента, хостинг вне платформы, оплата — по решению владельца (строкой в
  отчёте).
- Генерация текстов ИИ на проде — нет ключа (владелец, 2026-10-18).
- Телефонный робот, автодозвон — отклонено владельцем (2026-10-11).
- Источники с ключом (2ГИС, Яндекс) — R8.

## Открытые вопросы (PLACEHOLDER — уточнить у владельца)

- P1. Цена сайта под ключ и ежемесячной поддержки (R16). По умолчанию 15 000 ₽ и 1 500 ₽/мес —
  владелец меняет в админке.
- P2. Ниши для агента «Сайты» по умолчанию: стоматология, автосервис, шиномонтаж, салон красоты,
  ветклиника — владелец меняет план в админке.
- P3. Ключи 2ГИС / Яндекс Геопоиска для более полного поиска (R8).
