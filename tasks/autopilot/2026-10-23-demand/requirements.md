# Требования

- R1. Сообщение «Сегодня N заявок рядом — выйдите на линию» получает руководитель (PROVIDER_ADMIN) компании-исполнителя с техникой; парк СпецПласт16 не получает (владелец и так видит все заявки).
- R2. N — число настоящих заявок в статусе OPEN, созданных сегодня (с 00:00 по Москве), которые подходят компании по тем же правилам, что и уведомление о новой заявке (`providerMatchesOrder`: техника, радиус от базы, город).
- R3. При N = 0 ничего не отправляется.
- R4. Не чаще одного сообщения в сутки (по Москве) на пользователя; повторный вызов крона в тот же день второго сообщения не шлёт (захват в базе, как у «Актуализации»).
- R5. Отправляется только в дневное окно 09:00–20:00 по Москве.
- R6. Исполнителю, который сейчас на линии (свежая `LinePresence.online`), сообщение не отправляется — он уже на линии.
- R7. Каналы — push в приложение и Telegram, по настройкам пользователя; e-mail, WhatsApp и SMS это сообщение не используют.
- R8. Выключатель «Спрос рядом (раз в день)» в «Уведомлениях» на сайте и в приложении; по умолчанию включён; выключенный — сообщений нет. Виден только тем, кому сообщение может прийти (R1).
- R9. Нажатие на сообщение ведёт туда, где выходят на линию / видят заявки (приложение — экран заявок/линии, сайт — `/orders`).
- R10. Запуск — из `/api/cron/notices` (GitHub Actions каждые 5 минут, только production), с ограничением времени, не мешая отложенным уведомлениям «Пригласи друга».
- R11. Схема: только новые колонки `NotificationSettings.demandNudge Boolean @default(true)` и `demandNudgeSentAt DateTime?`; enum не меняется.
- R12. Тесты vitest: подсчёт N, окно времени, сутки по Москве, захват «раз в день», текст (склонение «заявка/заявки/заявок»), выключатель и права API; каждый тест падал бы без новой функции.

## Вне объёма

- Рассылка заказчикам и машинистам; SMS/e-mail.
- Число исполнителей на линии в тексте; персональные советы по цене.
- Новые Vercel cron (на Hobby их уже два).

## Открытые вопросы

- Нет: окно 09:00–20:00 и путь по нажатию выбраны по смыслу «сегодня … выйдите на линию».

Проверка на противоречия: рассылка только тем, у кого есть аккаунт и включены уведомления
(согласие на сервисные уведомления — часть аккаунта, выключатель есть) — не реклама третьим
лицам; число — из настоящих заявок (запрет фальшивых счётчиков соблюдён).
