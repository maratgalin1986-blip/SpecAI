# Бриф: приложение догоняет сервер (карта, линия парка, адрес заявки, тексты)

Дата: 2026-11-12. Отдельной сессии «Приложение» больше нет — работу делает сессия сайта по просьбе
владельца. Источник задач — записи `docs/sessions/handoff.md` от 2026-11-08 и 2026-11-11: сервер уже
в продакшене, приложение отстаёт.

Что нужно:

  отдаёт всех исполнителей с новыми полями, заявки заказчиков и принимает окно карты. Приложение
  должно это показать и дать исполнителю два переключателя.
- **B. Парк СпецПласт16 всегда на линии** (владелец, 2026-11-11). Машины парка приходят в `machines`
  без GPS, все в точке базы, `base` пуст — на карте не должно быть стопки значков.
- **C. Адрес заявки до брони** (PR #53). Исполнителю без подтверждённой брони сервер отдаёт только
  город и километры от базы — приложение не должно падать и писать «null».
- **D. Тексты.** Убрать «ИИ-агенты — круглосуточно», показать ответ сервера, когда восстановление
  пароля по почте выключено (503).

Границы: только `apps/mobile/**`; `apps/web` не меняется; структура приложения, клиент API и типы
сохраняются; публикация (push, PR, EAS Update) — за координатором.
