# Приёмка по требованиям

Проверено 2026-11-12 в рабочей копии: `pnpm lint`, `pnpm typecheck`, `pnpm format:check`,
`pnpm test` (приложение — 31 файл, 219 тестов), `npx expo export --platform android` — без ошибок.
Страница карты дополнительно открыта в настоящем браузере (Chrome без окна, 390×800, Leaflet 1.9.4):
ошибок в консоли нет, сообщения приложению приходят как описано ниже. На телефоне не проверялось.

| №   | Требование                              | Чем подтверждено                                                                                                                                |
| --- | --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| R1  | Кольцо «на линии», приглушённый значок  | `providersMapEveryone.test.ts` (классы `pin on` / `pin off`, старый сервер — без класса); снимок страницы в браузере                            |
| R2  | Карточка: город, техника, цена, без дат | `providersMapEveryone.test.ts` («the card data…»): в данных страницы нет полей дат                                                              |
| R3  | «Позвонить» или «Написать»              | там же: `{type:'call', href:'tel:+7…'}`; при `phone: null` — только «Написать», номера в карточке нет; `safeTel` не пропускает чужие ссылки     |
| R4  | «Заказчик рядом»                        | там же: значок, пометка «примерно», `{type:'order', id, orderUrl}`; переход — `ProvidersMap.tsx` (исполнитель — экран заявки, остальные — сайт) |
| R5  | Центрирование и список ближайших        | `providersMapEveryone.test.ts` («a tap centres…»), `liveGroups.test.ts` («кто рядом…»): расстояние, имя, техника; строка открывает значок       |
| R6  | Запрос по окну карты                    | `bboxParam`, `mergeInBox`, одно сообщение `bbox` после паузы, новые точки ждут закрытия карточки — `providersMapEveryone.test.ts`               |
| R7  | Два переключателя                       | `mapSwitchOn` (тест), `MyMapPinCard.tsx`: сохраняются сразу, при ошибке возвращаются; на телефоне не нажимались                                 |
| R8  | Парк — один значок со списком           | `liveGroups.test.ts` (`groupLive`, `toLiveMarkers`), страница: «2 машины на линии · СпецПласт16», строка → `{type:'machine'}`                   |
| R9  | Пустой `base`                           | `basePins.test.ts` (значок компании возвращается), `providersMapEveryone.test.ts` («на базе» от старого сервера рисуется)                       |
| R10 | Город и «≈ N км от вашей базы»          | `orderPlace.test.ts`; лента и экран заявки читают место только через `orderPlace`                                                               |
| R11 | Без координат — без точки и без «null»  | `orderPlace.test.ts` (нет базы и города; адрес из описания не подставляется)                                                                    |
| R12 | Полный адрес после брони                | `orderPlace.test.ts` («the customer and the booked provider…»)                                                                                  |
| R13 | Текст про помощника                     | `lib/site.ts`, `app/about.tsx`; поиск «круглосуточно» по `apps/mobile/src` пуст                                                                 |
| R14 | 503 при восстановлении пароля           | `passwordReset.test.ts`; экран входа показывает текст сервера под ссылкой                                                                       |
| R15 | Проверки                                | см. первую строку                                                                                                                               |

Не проверено без телефона: вид карточки поверх шторки заказа на главном экране, набор номера по
`tel:`, переключатели в кабинете на живом сервере, поведение WebView на старых Android.
