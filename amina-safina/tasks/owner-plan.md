## Шаг 1. Telegram-канал (5 мин, с телефона)
1. Telegram → ✏️ (новое сообщение) → «Создать канал».
2. Название: `Амина Сафина | AI-модель`. Описание — «Короткое био» из пакета. Фото — аватар.
3. Тип: «Публичный», ссылка `aminasafina` (если занято — `amina_safina_ai`).
4. Опубликуйте «Приветственный пост» + фото с яхты.
5. Пришлите мне ссылку на канал.

## Шаг 2. Сообщество VK (10 мин)
1. vk.com → слева «Сообщества» → «Создать сообщество» → «Тематическое сообщество» (или «Блог/Автор»).
2. Название — как в Telegram; тематика «Мода и стиль»; возрастное ограничение **не ставить 18+** (иначе VK Donut недоступен).
3. Управление → Основная информация: описание из пакета, адрес `aminasafina`.
4. Загрузите аватар и обложку (Управление → Обложка).
5. Опубликуйте приветственный пост. Пришлите ссылку.
6. VK Donut: Управление → «Монетизация» / «VK Donut» → «Подключить». Там будет проверка данных и привязка **карты РФ** — делаете сами, реквизиты мне не присылайте. Если VK потребует статус самозанятого/ИП для физлица — сообщите, что увидели (скриншот без реквизитов).

## Шаг 3. Boosty (10 мин)
1. boosty.to → «Войти» → через VK ID или телефон.
2. «Стать автором» → имя `Амина Сафина | AI-модель`, адрес `aminasafina`, описание из пакета, аватар, обложка.
3. «Уровни подписки» → создайте 3 уровня: 149 / 299 / 499 ₽, тексты из таблицы «Тарифы».
4. «Выплаты» → добавьте **карту РФ** (сами). Если Boosty спросит налоговый статус — выберите «физлицо», если такой вариант есть; если только НПД/ИП — пришлите скриншот экрана без данных.
5. Пришлите ссылку на страницу.

## Шаг 4. Налоги физлица (раз в год)
- Доход физлица от подписок облагается НДФЛ 13% (по общим правилам). Площадка обычно налог не удерживает — тогда до **30 апреля** следующего года подаётся декларация 3-НДФЛ (Госуслуги / ЛК налоговой), налог платится до **15 июля**.
- Я веду учёт поступлений в `reports/` — для декларации нужна только выписка.
- Сравнение: самозанятость = 4% вместо 13% и без декларации (оформляется за 5 мин в «Мой налог»). При 100 подписчиках это ≈ 2 000 ₽/мес экономии. Решение за вами.

## Чего НЕ делать
- Не присылать в чат пароли, коды из СМС, номер карты.
- Не покупать накрутку подписчиков.
