# AMINA SAFINA — инструкция проекта

Коммерческий виртуальный AI-блогер. Персонаж вымышленный, 26 лет, совершеннолетний.
Этот каталог — отдельный проект, к SpecAI/ИИСтройка24 не относится (живёт на ветке
`claude/amina-safina-setup`; рекомендуется вынести в отдельный репозиторий).

## Жёсткие правила
- Везде раскрываем: «Амина — виртуальный AI-персонаж». В био, в первом посте, в описании тарифов.
- Только fashion / glamour / купальники / lifestyle. Без обнажёнки, без интимных частей тела,
  без несовершеннолетних образов, без лиц реальных людей.
- Без накруток, ботов и фальшивой активности. Реклама — с маркировкой (ОРД/erid), если платная.
- Аккаунты, KYC, банк, платежи, подписки на платные сервисы — только владелец (см. `tasks/owner-actions.md`).
  Пароли/коды/реквизиты в чат не просить.
- Платные покупки — только после подтверждения владельца. Бюджет: `memory/budget.md`.
- Не утверждать, что изображение/аккаунт создан, если его нет.

## Экономия
- Сначала читать `memory/state.md` (≤ 40 строк) — там текущее состояние и следующий шаг.
- Не перегенерировать то, что есть в `assets/catalog.csv`.
- Простые задачи — дешёвая модель; субагенты только под узкую задачу.
- В конце сессии — `/session-report` (skill), обновить `memory/state.md`.

## Структура
| Путь | Что |
|---|---|
| `.claude/agents/` | 8 узких агентов (business, content, image, video, social, platform, analytics, tech) |
| `.claude/skills/` | `amina-image` (генерация по эталону), `amina-post` (пост в голосе Амины), `session-report` |
| `memory/` | `persona.md` (паспорт и визуальный канон), `state.md`, `budget.md` |
| `tasks/` | `todo.md` (этапы 1–9), `owner-actions.md` (что делает только владелец) |
| `reports/` | проверки платформ, финмодель, отчёты сессий |
| `assets/` | `reference/` эталон, `images/*`, `video/`, `catalog.csv` |
| `content/` | `calendar.csv`, посты, сценарии |
| `automation/` | `finance.py` (финмодель), `catalog.py` (учёт ассетов) |

## Генератор
Canva MCP `generate-image` (работает, бесплатно в рамках квоты аккаунта Canva). Эталон: Canva media id
`MAHaJmnyMTM` — передавать в `imageReferences` для консистентности лица. Полное разрешение —
только в Canva (локально превью). Альтернативы при отказе/квоте — в `memory/state.md`.
