# Claude Code Projects: один координатор для сайта и приложения

Владелец, 2026‑10‑12: «после слияния PR #55 перевести работу в Claude Code
Projects — делай». PR #55 слит, продакшен обновлён. Проект создаёт владелец в
claude.ai/code (из облачной сессии это сделать нельзя); ниже — куда нажать и
что вставить. Источник: https://code.claude.com/docs/en/claude-projects.md
(бета для Pro и Max; если в левой колонке claude.ai/code нет пункта
**Projects**, доступ ещё не выдан — лист ожидания claude.com/form/projects).

## Шаги для владельца (5 минут)

1. claude.ai/code → слева **Projects** → **New project**.
2. **Name**: `ИИСтройка24`. **Goal**: «Агрегатор спецтехники: сайт, приложение,
   продвижение». В **Context** → **Add** → репозиторий `maratgalin1986-blip/SpecAI`
   (нужны push‑доступ и установленное приложение Claude на GitHub — оба уже есть).
   → **Create project**.
3. Шестерёнка в шапке проекта → **Project settings** → **Memory** →
   **Project instructions** → вставить текст из раздела «Инструкции проекта»
   ниже (лимит 16 000 знаков, текст укладывается). Сохранить.
4. **Project settings** → **Environment** → выбрать ту же облачную среду, в
   которой работают нынешние сессии (в ней `EXPO_TOKEN`, разрешённые хосты
   `api.expo.dev`, `exp.host`, `api.telegram.org`, `api.resend.com`,
   `api.vercel.com`). Без этого треды получат среду «Default» без переменных.
5. Нынешние сессии: в боковой панели у сессии «Приложение» → меню → **Move to
   project** → `ИИСтройка24`; то же для сессии сайта. Старые сессии остаются,
   ничего не теряется.
6. Первые треды (по одному сообщению каждый, тексты в разделе «Первые треды»).

Ограничения беты: 200 новых тредов в день, один пользователь на проект, тред
нельзя перенести в другой проект; `CLAUDE.md` из репозитория треды читают
по‑прежнему, инструкции проекта его дополняют, а не заменяют.

  PostgreSQL; packages/shared — zod-схемы, категории техники

  getRequestUser(request) в API понимает оба.

  ADMIN_PASSWORD (разделы Исполнители, Воронка, Лента, модерация).
- Уведомления: lib/notifications (Telegram по ссылке t.me/<bot>?start=n_…,
  push Expo, e-mail Resend; WhatsApp/SMS подготовлены, выключены). Cron:
  /api/cron/weekly (пн 05:00 UTC) и /api/cron/daily (16:00 UTC = 19:00 МСК:

КАК РАБОТАЕМ (один тред = одна задача = одна ветка = один PR)
1. Перед каждым push: merge origin/main, затем pnpm lint && pnpm typecheck &&

7. Коммиты и PR заканчиваются строками атрибуции, которые даёт сессия; имена

9. Тексты — по-русски, «заявка» (не «наряд»), название «ИИСтройка24», подпись
   «от СпецПласт16»; никаких упоминаний Яндекса/Авито как бренда в продукте.
10. Проверка продукта: локальная копия сайта на тестовой базе
