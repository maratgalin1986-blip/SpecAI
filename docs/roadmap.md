Поручение владельца 2026-10-22: «Делай всё сам, улучшайся, учись работать без меня, удалённо».
Большие задачи (не «одно маленькое улучшение») идут через навык `.claude/skills/autopilot` —
бриф → требования → спецификация → план → разработка → ревью → приёмка — и сливаются сами,
когда CI зелёный и приёмка пройдена. Один прогон — одна задача. Порядок — по пользе для главной
цели: агрегатор заявок на спецтехнику по всей России, «как Яндекс Такси», все заявки через
платформу (владелец, 2026-10-22); потом комиссия — по его команде (`docs/launch-plan.md`). Задачи только из решений владельца и его
запросов; новые идеи сначала записываются сюда как «предложено», берутся в работу после
того, как остальные сделаны.

## Предложено: Яндекс Go и Авито (2026-10-28)

Разбор — `docs/ideas-yandexgo-avito.md`. Цена до заказа и доверие на карточке каталога уже
сделаны (PR 2026-10-28). Статус всех строк ниже — «предложено»:

- «Ищем исполнителя… откликнулись N» — живой статус заявки без перезагрузки (M).
- Время подачи и фото машины в ставке исполнителя (M).
- «Заказать снова» у выполненного заказа (S).
- Классы внутри вида техники с ценой у каждого (мини/средний/тяжёлый, кран 25/32 т) (M).
- Заказ «как такси»: адрес первым шагом, сохранённые адреса (M).
- Избранное на карточках каталога (M).
- Подсказки в поиске каталога: виды, модели, города (S).
- Фильтр каталога по характеристикам: грузоподъёмность, высота, вылет (M).
- Чат «спросить исполнителя» до заявки, через площадку, с маской контактов (M).
- Позиция исполнителя на карте для подтверждённой брони (L).
- Подменный номер для звонков — только по решению владельца (договор с оператором) (L).
