# Память ИИ-офиса

Общий контекст, который агенты читают перед работой и дополняют после.
Источник истины для живых данных (заявки, бронирования, оплаты) — база
платформы; здесь то, чего в базе нет: правила, договорённости, решения.

| Файл           | Что внутри                                                       | Кто обновляет        |
| -------------- | ---------------------------------------------------------------- | -------------------- |
| `prices.md`    | Прайс, подача, минимальный заказ, скидки, сезонные цены          | Директор             |
| `fleet.md`     | Машины, машинисты, навесное, ограничения (вес, габариты), ТО     | Механик, агент парка |
| `clients.md`   | Постоянные клиенты: что заказывают, как платят, особые условия   | Агенты + директор    |
| `partners.md`  | Партнёры-поставщики: техника, район, рейтинг, комиссия           | Агент партнёров      |
| `decisions.md` | Журнал решений: дата, что решили, почему, что изменили в агентах | Директор             |

Правило: если человек исправил работу агента, исправление попадает сюда или в
инструкцию агента в тот же день. Так следующий запуск работает лучше.

Персональные данные клиентов (телефоны, паспорта) сюда не пишем — они живут в
базе с разграничением доступа.
