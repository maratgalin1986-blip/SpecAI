# Строительные и «технические» Telegram-чаты по России: куда звать бота-диспетчера

2026-10-17. Порядок работы: бот добавляется в чат **только админом чата** (страница
`/bot`), отвечает под заявкой ссылкой на площадку, не пишет в личку и не рассылает
рекламу; админ выключает его командой `/quiet`. Номера из чатов не используются для
SMS, пушей и сообщений — это реклама без согласия (ФЗ «О рекламе», ст. 18; 152-ФЗ).
Как вести переговоры с админами и учёт — `docs/telegram-chats.md`.

TGStat перед обращением к админу. Мёртвые чаты (нет сообщений неделю) вычёркивать.

## Как найти чаты каждого города (повторять для каждого города, где есть исполнители)

1. **TGStat** — поиск чатов по запросам «<город> спецтехника», «<город> стройка»,
   «<город> прорабы», «<город> грузоперевозки», «<город> объявления»; сортировка по
   активности (MAU) — [рейтинг «Строительство»](https://tgstat.ru/en/ratings/chats/construction?sort=mau).
2. **tg-cat** — поиск групп по слову «спецтехника»
   [tg-cat.com](https://tg-cat.com/?search=%D1%81%D0%BF%D0%B5%D1%86%D1%82%D0%B5%D1%85%D0%BD%D0%B8%D0%BA%D0%B0&type=supergroup&lang=en).
3. **Городские доски объявлений** «Объявления <город>» — есть сеть таких чатов более чем
   по 100 городам; это общие чаты, из них — ссылки на тематические.
4. **Чаты СНТ, коттеджных посёлков, новостроек** — септики, планировка, вывоз грунта.
5. Поиск прямо в Telegram по тем же словам.

## Что предложить админу чата (коротко)

> Здравствуйте! Мы — {SITE.platform}, бесплатная площадка заказа спецтехники. Наш бот
> отвечает на заявки о технике в вашем чате ссылкой, где исполнители присылают цены. Он
> не пишет в личку и не рекламирует ничего постороннего; выключается вашей командой
> `/quiet`. Активным чатам — бонус за подключение. Подробнее: <сайт>/bot
