# Блок «ИИСтройка24 — бесплатно и без посредников» для сайта СпецПласт16

Просьба владельца (2026-10-17): на его сайте, который рекламируется в Яндекс Директе, —
яркая ссылка на приложение с акцентом «бесплатно и без посредников».

Сайт сделан не в этом репозитории, поэтому здесь готовые к вставке материалы:

| Файл                   | Что это                                                            |
| ---------------------- | ------------------------------------------------------------------ |
| `snippet.html`         | Код: яркий баннер в странице + кнопка, прилипшая к низу экрана     |
| `banner-1200x400.png`  | Картинка-баннер для конструкторов без вставки кода (широкий)       |
| `banner-1080x1080.png` | Квадратный баннер (мобильная версия сайта, соцсети, Яндекс Бизнес) |

Ссылки ведут на `https://spec-ai-web.vercel.app/` с метками
`utm_source=specplast16_site` (`utm_medium=banner` или `sticky`): переходы с сайта видны в
/admin → «Маркетинг». Для картинки ставьте ссылку
`https://spec-ai-web.vercel.app/?utm_source=specplast16_site&utm_medium=image&utm_campaign=app`.

## Куда вставить

- **Тильда**: «Добавить блок» → «Другое» → **T123 «HTML-код»** → вставить весь `snippet.html`.
  Блок поставить сразу под первым экраном. Кнопка внизу экрана появится на всех
  страницах, где есть этот блок.
- **WordPress**: блок «Произвольный HTML» → вставить `snippet.html`.
- **Wix / uKit / Craftum / Nethouse**: элемент «Встроить код» / «HTML» → вставить `snippet.html`.
- **Конструктор без вставки кода** (например, сайт в Яндекс Бизнесе): добавить картинку
  `banner-1200x400.png` (на телефоне — `banner-1080x1080.png`) и указать ссылку выше.

После публикации открыть сайт с телефона и проверить, что кнопка внизу не закрывает
кнопку звонка или чат, если они там есть. Если закрывает — оставить только баннер
(первую часть кода).

## Почему формулировка именно такая

«Бесплатно и без посредников» стоит рядом с пояснением «цену назначает владелец техники,
расчёт — напрямую с ним, площадка не берёт процент». Это правда, пока онлайн-оплата
выключена и комиссии нет (`apps/web/src/lib/stripe.ts`). Реклама должна быть
достоверной (ФЗ «О рекламе», ст. 5), а Директ проверяет посадочную страницу. Если
появится комиссия, этот блок нужно заменить вместе с `SITE.promise`.
