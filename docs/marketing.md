## Заставка при входе (≈3 секунды)

- Вид с квадрокоптера над стройкой, «ООО «СпецПласт 16» представляет», карта
  партнёра с телефоном. Длина — около 3 секунд: маркетологи и UX-специалисты
  советуют заставки не дольше 2–3 секунд и всегда с кнопкой «Пропустить».
  По данным Google, когда страница грузится 3 секунды вместо 1, вероятность,
  что посетитель уйдёт, растёт примерно на 32 %. Поэтому заставка:
  - показывается **один раз за визит** (при повторных обновлениях в той же
    вкладке её нет — иначе она раздражает и снижает заявки);
  - пропускается кликом, любой клавишей или кнопкой;
  - не показывается людям, у которых в системе отключена анимация;
  - не задерживает загрузку сайта: он грузится под ней.

## Яндекс.Метрика (бесплатно)

Код уже на сайте, нужен только номер счётчика:

1. Зайти на https://metrika.yandex.ru → «Добавить счётчик» → адрес сайта.
2. Включить «Вебвизор» (запись действий посетителей).
3. Прислать номер счётчика — он пропишется в Vercel как
   `NEXT_PUBLIC_YANDEX_METRIKA_ID`.
4. Счётчик 113179760 уже подключён. В Метрике → «Цели» создать цели типа
   «JavaScript-событие» (идентификатор — как в таблице). Сайт уже отправляет
   все эти события; без целей в интерфейсе они не видны в отчётах.

   | Идентификатор               | Что значит                                   | Главная? |
   | --------------------------- | -------------------------------------------- | -------- |
   | `lead`                      | заявка отправлена (любая форма)              | да       |
   | `call`                      | нажали на номер телефона                     | да       |
   | `whatsapp`                  | перешли в WhatsApp                           | да       |
   | `telegram`                  | перешли в Telegram                           | да       |
   | `email`                     | нажали на e-mail                             |          |
   | `hero_call`                 | звонок с первого экрана                      |          |
   | `card_open`                 | открыли карточку техники из каталога         |          |
   | `geo_found` / `geo_fail`    | адрес работ нашёлся / не нашёлся на карте    |          |
   | `window_book`               | бронь «окна» из прогноза погоды              |          |
   | `lead_retry`                | заявка ушла со второй попытки (плохая связь) |          |
   | `intro_skip` / `intro_full` | заставку пропустили / досмотрели             |          |

   Совет: сделайте составную цель «Контакт» = `lead` или `call` или
   `whatsapp` или `telegram` — это и есть главная конверсия сайта.

5. Превью-версии и ваша админка в Метрику не пишутся, так что цифры чистые.
6. В /admin у каждой заявки отмечайте итог («Сделка», сумма) — тогда в отчёте
   «Маркетинг» и в сводке по понедельникам видно, какие каналы приносят
   деньги, а не только заявки.

**Cookie и согласие (решение 2026-10-03).** Внизу при входе — маленькая плашка
«Обработка персональных данных и cookie»: «Согласен» или ✕ «Скрыть» (скрыть —
ни согласие, ни отказ, Метрика работает как до ответа). Отказ — только на
`/privacy`. До выбора Метрика
считает визиты и цели без Вебвизора — как раньше (opt-out). Переход на
«только после OK» не сделан сознательно: большинство посетителей не нажимает
ни одну кнопку, и Директ потерял бы почти все конверсии для обучения.
«Согласен» включает Вебвизор (на той же странице, если счётчик ещё не
загрузился, иначе со следующей). «Отключить Метрику» на `/privacy` сразу
останавливает цели и загрузку tag.js, а со следующей загрузки счётчик не
инициализируется вовсе. Выбор
можно изменить на `/privacy` (кнопки «Включить / Отключить Метрику»). Код:
`components/CookieNotice.tsx`, `components/YandexMetrika.tsx`,
`stopMetrika` / `enableWebvisorIfQueued` в `lib/marketing.ts`.

## Как размечать рекламу

Ставьте в ссылку объявления метки, тогда в админке будет видно каждую кампанию:

```
https://spec-ai-web.vercel.app/?utm_source=avito&utm_medium=ads&utm_campaign=ekskavator
https://spec-ai-web.vercel.app/?utm_source=2gis&utm_medium=card
https://spec-ai-web.vercel.app/?utm_source=vk&utm_medium=post&utm_campaign=kran
https://spec-ai-web.vercel.app/?utm_source=yandex&utm_medium=cpc&utm_campaign=direct-kran
```

QR-код со страницы /qr уже размечен (`utm_source=qr`) — печатайте его на
визитках, технике и объявлениях, переходы будут видны отдельным каналом.
Ссылки с `utm_medium=cpc`, `yclid` или `gclid` открывают сайт без заставки —
человек из рекламы сразу видит номер телефона.

## План маркетолога на первый месяц

1. **Яндекс Бизнес и 2ГИС** — карточка компании с фото техники, телефоном и
   ссылкой на сайт (с меткой `utm_source=2gis`). Для аренды техники в городе
   это главный бесплатный источник звонков.
2. **Авито** — объявления по каждому виду техники со ссылкой на сайт.
3. **Яндекс Директ** — поиск по запросам «аренда экскаватора-погрузчика
   Набережные Челны», «автокран аренда Челны», «манипулятор 7 тонн»; небольшой
   дневной бюджет, через 2 недели смотреть в админке, какие запросы дали заявки.
4. **Отзывы** — после каждой смены просить клиента оставить отзыв в 2ГИС и
   Яндекс Картах. Отзывы — главный фактор выбора подрядчика.
5. **Раз в неделю** открывать `/admin` → «Маркетинг» и Метрику: какой канал дал
   заявки, какой нет — бюджет переносить в работающие каналы.
6. **Свои видео с объектов** — заменить стоковые на сайте; реальные машины и
   люди повышают доверие сильнее любых эффектов.

## A/B: кино или спокойно

Отключено по решению владельца: кино-эффекты видят все посетители. Спокойную версию
можно посмотреть для сравнения по ссылке с `?ab=calm` (вернуть кино — `?ab=cine`).

## Разведка конкурентов и практик, 2026-11-12 (сессия офиса)

Владелец: «Самообучайся, подсмотри конкурентов». Один проход поиска по открытым источникам; цифры из
статей — ориентиры, не измерения, проверяем своими рассылками.

**Холодные письма о сайте.**

- Лучше отвечают на письма в 30–150 слов, одна мысль — одно предложение, один простой шаг в конце
  («показать, как это выглядит для вас?»), тема — про ситуацию получателя, а не «предложение».
  Средний ответ на холодные письма — единицы процентов. Наше письмо длиннее (около 170 слов плюс
  список) и заканчивается «ответьте или позвоните». → Сократить первое письмо до 3 коротких абзацев и
  одного вопроса; подробности — в презентации `/pokaz`.
- Студии отмечают: решение о сайте «зреет», сделки приходят после повторного касания. → Напоминание
  через несколько дней важно; сейчас оно уходит только по кнопке владельца.

**Цены на сайты.** Студии: лендинг от десятков тысяч рублей, сайт — сотни тысяч; конструкторы —
до 5 000 ₽ в месяц, но делать самому. Наши 15 000 ₽ и 1 500 ₽ в месяц — нижняя граница рынка «под
ключ». → Позиция: «готовый сайт дешевле студии и без возни с конструктором»; пакет «Лендинг» ниже
«Сайта» — цены ждём от владельца.

**Площадки спецтехники.** «Авито Спецтехника»: заказчику бесплатно, с исполнителя комиссия 10 % от
аренды; онлайн-заказ полного цикла тестируют в отдельных регионах. «Спецшеринг»: берёт на себя поиск,
проверку контрагентов, расчёты и документы. → Наше отличие для исполнителя — без комиссии с заказа и
цену называет он сам; для заказчика — исполнители рядом на карте. Это должно стоять первым в письмах
площадки.

**Ящик и объём.** Яндекс точного лимита не называет; сторонние источники дают около 500 писем в сутки
для бесплатной почты и до 3 000 для Яндекс 360, лимит снижают при жалобах на рекламу, блокировка —
на сутки и продлевается при попытках отправки; опасны всплески. → Постепенный рост лимита оставить;
для 300 + 300 в день — отдельные ящики Яндекс 360 на своём домене.
